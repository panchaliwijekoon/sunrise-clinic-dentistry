🦷 Sunrise Dental Clinic Help

Quick guide for using the clinic management system

1. Login

Enter the provided username and password, then click Sign In.

2. Register Appointment

  1. Open the dashboard.
  2. Select Register Appointment.
  3. Enter the patient name.
  4. Select the dentist.
  5. Select the appointment date and time.
  6. Click Register Appointment.

3. Search / View Appointments

  1. Select Search/View Appointments.
  2. Use the search box to search by patient, dentist, or status.
  3. Select Edit to update an appointment.
  4. Select Cancel to cancel an appointment.

4. Calculate Bill

  1. Select Calculate Bill.
  2. Enter the patient name.
  3. Select the treatment.
  4. Enter the consultation fee and treatment charge.
  5. Enter a discount if required.
  6. Select the payment method.
  7. Click Calculate Bill.
Tip: Make sure the discount does not exceed the subtotal.

5. Print Receipt

After calculating the bill, click Print Receipt. You can print the receipt directly or save it as a PDF.

6. Reports

Select Reports from the dashboard to view appointment totals, scheduled appointments, cancelled appointments, bills, and revenue.

7. Logout

Select Logout from the dashboard to securely leave the system.
